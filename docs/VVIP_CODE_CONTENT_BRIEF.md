# VVIP Code — content brief

Paste this into Claude to generate Internal Mail, Push and SMS copy.
Built from the 23 Jul test, where the copy reached everyone but only 1.3% claimed.

---

## THE OFFER (fixed — never change these facts)

- Player deposits **RM100+** on the event day
- They claim **one** surprise code: **RM12 or RM18**, 50/50 luck, revealed only after claiming
  *(internal fact — these numbers must never appear in any message; see non-negotiable 2)*
- **One claim per player. Event day only. Expires 23:59.**
- Zyra brands, VIP Tier 3 and Tier V
- **A human sends the code.** It is not automatic and not self-service.

---

## THE 5 NON-NEGOTIABLES

These come from what actually broke on 23 Jul. Every message must obey all five.

**1. Always give TWO ways to claim — never Telegram only.**
On 23 Jul the only CTA was a Telegram bot link. Of players **who qualified** (deposited RM100+),
those with Telegram claimed at **40.7%**; those without claimed at **0.9%**. 226 people deposited
RM100+ and had no way to ask for their code. Every message must carry a Telegram route **and** a
non-Telegram route — see the next section.

**2. Never state the amount — sell the curiosity, but keep it honest.**
No RM12, no RM18, no "up to RM__". The unknown is the hook: they open it to find out. This is
deliberate and it works — on 23 Jul, players who could actually reach the CTA claimed at **12.9%**
with exactly this vague framing.

The guardrail: build curiosity **without inflating it**. Say the credit is real and worth opening;
never hint it could be large, never imply a jackpot. A player who chases it and receives RM12 must
feel they got a nice surprise, not a let-down. Tease the mystery, not the size.

Safe: `a surprise code reserved in your name` · `real free credit inside` · `luck decides`
Not safe: `up to RM18` (kills the mystery) · `big reward` / `huge credit` (sets up a let-down)

**3. Never tell someone who already deposited to deposit again.**
The old follow-up said "Deposit RM100+ to unlock" to people who had already deposited. It read as "you don't qualify" and stopped them. Audience B (below) must never contain a deposit instruction.

**4. Never imply self-service.**
No "tap to open", no "click to reveal". The code does not open itself — our team sends it. Promise what actually happens: *message us and we'll send your code*.

**5. Never put the actual code in any message.**
The RM100 gate depends on our team releasing it after verifying the deposit. A code in a blast breaks the whole promotion.

## THE CLAIM ROUTES

Only ~9% of a typical pool has a Telegram link, so Telegram can never be the only door.

**Route 1 — Livechat (the primary one; works for everyone).**
Every player can reach Livechat from the site or app — no link needed, nothing to install. This is
the default route and should lead in every message.
Wording: `message us on Livechat` · `open Livechat and say CLAIM`
> ⚠️ Fill in the exact entry point before sending: `<LIVECHAT_URL>`

**Route 2 — Telegram (secondary; only for players who already use it).**
Keep it, it converts well for the minority who have it — but never alone, and never first.
Wording: `or ping us on Telegram` + `<TELEGRAM_BOT_LINK>`

**Route 3 — SMS reply keyword (optional, only if the gateway supports inbound).**
`Reply CLAIM` is the lowest-friction option of all — no app switch, no link.
> ⚠️ Confirm with the SMS provider whether inbound replies are received and routed. If not, use
> Route 1 wording in SMS instead.

**How each channel carries them:**

| Channel | Routes to show |
|---|---|
| **Internal Mail** | Both. Livechat first as the main CTA, Telegram beneath as "or". |
| **Push** | Livechat only — no room, no links. "Open the app and message us." |
| **SMS** | One only, at 160 chars. `Reply CLAIM` if supported, else Livechat. Never Telegram. |

**Rule of thumb:** if a player has never touched Telegram, the message must still make complete
sense and be fully actionable. Read every draft back assuming Telegram does not exist.

## PER CHANNEL

### Internal Mail (longest — the main one)
Structure:
1. Subject — lead with the mystery, no clickbait and no amount
2. `Hi Boss,`
3. One line: a code is reserved in their name
4. **The hook** — real free credit inside, size is pure luck, no amount named
5. **The steps** — numbered, explicit: deposit RM100+ → message us → we send the code
6. **Both claim routes** — Livechat first as the main CTA, Telegram beneath as "or"
7. Deadline — today only, closes 23:59
8. Sign-off: `<BRAND>` / `VVIP Priority Support`

Length: 6–9 short lines. Emoji sparingly, max 4.

### Push notification (shortest)
- **Title:** ≤ 40 characters
- **Body:** ≤ 90 characters
- One idea only — mystery + action, never an amount
- No URLs (push opens the app) — so the CTA is **"open the app and message us"**, never Telegram
- Must work if it's the only thing they ever read

### SMS — **Manglish, one version only**
- **≤ 160 characters total**, including brand name
- Plain text, no emoji (renders badly, costs extra)
- One route only — `Reply CLAIM` if the gateway supports inbound, otherwise Livechat. **Never Telegram.**
- Must include: brand · offer · deadline · how to claim
- **Write it in Manglish, not formal English.** SMS is the one channel that does not get
  EN/ZH/MS versions — Manglish reads across the whole market, sounds like a person rather
  than a broadcast, and is naturally shorter, which matters at 160 characters.

**Register:** natural spoken Malaysian English. Light touches only — `boss`, `already`, `got`,
`can`, `just`, `today only`. Do **not** pile on particles or write a parody. It still has to sound
like a premium brand talking to a VIP, just informally.

Good: `Boss, got a surprise code waiting for you at BM69. Real free credit inside. Reply CLAIM.`
Too much: `Wah boss!! Confirm got one lah, very shiok one, come lah!!`
Too stiff: `Dear valued customer, we wish to inform you that a reward is available.`

## LANGUAGES

**Internal Mail and Push:** EN-MY, ZH-MY, MS-MY. Not literal translation — natural for each.
Keep "Boss" in all three; it works in this market.

**SMS:** Manglish only, single version (see the SMS section above).

---

## TONE

Warm, exclusive, a little playful about the luck. Talking to a valued regular, not a mailing list.
Tier V variant: more understated, no exclamation marks, framed as a thank-you.

---

## NEVER SAY

- "Win back your losses", or anything loss-chasing
- Fake countdowns or fake scarcity (the 23:59 deadline is real — use it, don't invent others)
- "Guaranteed" anything
- The actual redeem code
- "Tap to open" / "click to reveal"
