# VVIP Redeem Code — Floor SOP & Briefing
*Winning Together, Growing Forever.*

Two parts: a **briefing script** to read to the floor, and a **desk cheat sheet** to keep open on event day.

---

## PART 1 — BRIEFING SCRIPT (read this out)

**Start here — open with the why, not the steps.**

> "Okay team, gather up. Starting this cycle we're running a new one for our Zyra VIPs — it's called the **VVIP Code**. Forget the free spins, this replaces them.
>
> Here's the deal in one line: **our player deposits RM100 today, and we give them a surprise code worth RM12 or RM18.** They don't know which one they'll get — that's the fun of it, it's luck. Same player might get RM12 today and RM18 next round.
>
> **Why we're doing it:** it gives our VIPs a reason to come back and deposit on their day, every cycle. The surprise keeps them coming. That's retention, and that's our job.
>
> **Who's it for:** only the players on today's list. The system already picked them — Tier 3 and Tier V on the brand we're running today. If someone's not on the list, they don't get a code. Simple.
>
> **When:** codes are only good **on the event day**. Today's code dies at midnight. No 'I'll come back tomorrow'.
>
> **Now — how we actually do it. Three moves.**
>
> **One — we reach out FIRST.** Before they deposit, we message them. Tell them the offer: 'deposit RM100 today, claim your surprise code, up to RM18.' We log that contact. This part matters — if we didn't reach out first, we don't get credit for the save, even if they deposit. So contact first, always.
>
> **Two — they deposit, we check.** Player deposits RM100 or more. We **verify it in BO with our own eyes** before anything else. No verify, no code. If they only put RM60, they don't qualify yet — we mark it and they can top up.
>
> **Three — we release the code.** Open the **Campaigns** tab, search their UID, hit **Release**, pick where we're talking to them — Telegram or Livechat — and the code shows up. We send it. Done. The system remembers who released it and when.
>
> **The rules we do not break:**
> - Never send the code before we've seen the RM100 deposit. Never.
> - One code per player. The system blocks doubles, but don't try.
> - Not on the list = no code. Don't make exceptions for a friend.
> - Contact first, then deposit, then release. That order.
>
> **What we expect from you today:** work your list, reach out early, verify every deposit, release clean. If it's quiet, go capture the ones who haven't claimed yet. Any questions before we start?"

## PART 2 — DESK CHEAT SHEET (keep this open)

**The flow — every player, same 4 steps:**

1. **Reach out first** → message the player the offer, log the contact
2. **They deposit RM100+** → verify it in BO yourself
3. **Console → Campaigns tab → search their UID**
4. **Release** → pick Telegram / Livechat → send them the code

**What the search result tells you:**

| You see | It means |
|---|---|
| Gold card + Code A/B + **Release** | On the list, ready — verify deposit, release |
| **"not contacted yet"** amber tag | Reach out and log contact first |
| **"no code for this player"** | Not on today's list — politely, no code |
| Already released + a name + time | Someone already gave it — check the story |

**When it's not straightforward:**

- **Under RM100?** → hit **Not qualified**. Records it, keeps their code. They top up, come back, we release.
- **Wrong day?** → code's dead. Only today's list is live.
- **They lost the code?** → search again, it still shows — same one, one claim.

**The three "never":**
1. Never release before seeing the RM100+ deposit.
2. Never give a code to someone not on the list.
3. Never send the actual code in a mass blast — that's not us, that's the system.

**Slow spell?** → Click the no-link counter, go capture Telegram links for players who don't have one. That's tomorrow's reach.
